# LINOWORKS RECRUIT

架空企業「リノワークス」を想定した、1ページの採用サイトデモです。

円形の人物写真、ターコイズとライムの配色、仕事内容・人物ストーリー・募集要項・FAQ・応募案内を収録しています。

## 閲覧

index.html をブラウザで開いてください。HTML / CSS / JavaScriptによる静的サイトで、インストールやビルドは不要です。

## デモについて

企業・人物・発言・募集内容は架空のサンプルで、写真はイメージです。
応募受付と個人情報の収集・送信は行いません。
noindex,nofollow を設定しています。

## 更新

main ブランチへ変更をpushすると、GitHub Pagesへ反映されます。
